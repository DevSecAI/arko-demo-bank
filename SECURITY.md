# Security Policy — ArkoBank Demo Repository

## Intentional vulnerabilities

This repository contains **deliberately insecure code patterns** for product
demonstrations, security training, and static-analysis benchmarking. It is part
of the **ArkoBank** fictional demo suite intended for use with **ARKO** and
similar DevSec tools.

**Do not deploy this codebase to production.** Do not connect it to real
financial systems, identity providers, or payment processors.

All credentials, keys, card numbers, and personal data appearing in this repo
are **synthetic**. They are fabricated for scanner realism and must never be
treated as valid secrets.

## Reporting issues with the demo itself

If you discover accidental inclusion of real secrets, personal data, or material
that could enable misuse beyond static detection, please open a private
security advisory with the repository maintainers.

## Supported versions

This is a demo-only codebase; no production security SLAs apply.
